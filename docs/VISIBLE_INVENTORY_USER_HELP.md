# 显性库存策略（免费极致 · 真实性硬约束）

## 原则

1. **真实性**：只用可溯源 fetch；无数据 →「暂无」，禁止假填。
2. **可靠性**：仓单 + 交易所库存 + LME 交叉；口径标签写清。
3. **充足性**：不买付费，也要把公开源拉满并 heal 滞后。
4. **付费不做刚需**：Mysteel API / SMM 再贵也不作门槛。
