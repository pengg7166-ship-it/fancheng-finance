## 六条原则

### 1. 变化优先

市场、政策、持仓每天都在变。**任何「偏多/偏空」都只是当前快照**，不是永恒真理。  
系统用三时段快照、变更 Δ、存档复盘，让结论跟着世界一起动。

### 2. 研判为纲

**大宗走势研判**是理论基线：供需 × 金融环境、主矛盾/次矛盾、原油之母、跨境传导。  
缠论、量化、政策雷达都是输入或印证——**方向先由研判定**，再谈怎么入场。

### 3. 缠论为术

缠论 + 多周期 K 线（5m → 15m → 1h）解决「**往哪做**」之后的「**在哪做**」：  
支撑/阻力 touch、止损/盈利保护点值锁定。**术服从纲，不另起 alpha。**

### 4. 时段校正

每日三个固定时刻抓取预测快照，持续校正同一交易日的判断：

| 时刻 | 槽位 | 含义 |
|------|------|------|
| **20:55** | 夜盘前 | 日盘收盘后、夜盘开盘前 |
| **08:55** | 日盘前 | 夜盘结束后、日盘开盘前 |
| **13:25** | 午盘前 | 日盘午间、下午盘重启前 |

### 5. 实证对照

预测必须能被检验：方向中心、区间 high/low、三时段对照、研判存档。  
**命中与失手都写入复盘**——用实际走势修正下一版，而不是粉饰旧结论；**禁止为 UI 填充假数据**，缺失则标「待校验 / 暂无」。

### 6. 审慎 gate

哲学 filter（`PHILOSOPHY_FILTER_V2=1`）在环境 disagree 时主动过滤：

- 价格与哲学方向 **发散**
- **政策日**叙事冲突
- **利好兑现**（priced-in）
- 跨境 lead **冲突**

UI 徽章：**Phil✓** 通过 · **Phil·过滤** 观望。Quant 信号从属于研判 + 哲学 gate，不越权。

## 策略栈（自顶向下）

```
政策 · 新闻 · 宏观 · 量价 …
        ↓  变量层（每日变）
大宗走势研判 → 哲学 filter → Quant gate（方向）
        ↓  常量层（规则固定）
缠论 S/R 入场 → 止损/止盈 → 存档 / outbox
```
