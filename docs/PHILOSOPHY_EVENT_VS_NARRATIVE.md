# 事件 vs 叙事 — 历史验证与哲学编码（v1.30.2）

> 用户原则：**重大事件** → 短期剧烈波动 + 冲击后回撤/反弹；**叙事主题** → 更长周期、更高涨幅（CU/AL/AU/AG）。

数据来源：`data/history/news-tagged.csv` + `E:\FanchengFinance\data\history\trading\{cu,au,ag,sc,al}.json`  
验证脚本：`scripts/validate-event-vs-narrative.js` → `docs/event-vs-narrative-stats.json`

## 一、资讯原型对照

| 类型 | 代表行（news-tagged.csv） | 价格特征（实测） |
|------|---------------------------|------------------|
| **重大事件** | `2019-05-10` 关税25%；`2022-02-24` 俄乌；`2025-02-01` 特朗普关税；`2026-01-01` 美以伊 | T+5 内常出现 ≥3% 冲击；随后 5–20 日内剧烈回撤/反弹 |
| **叙事主题** | `2023-11-30` AI算力叙事；`2024-03-01` 数据中心铜需求 | T+20~T+60 累计涨幅显著高于事件型；回撤幅度相对温和 |
| **日常** | FOMC 决议日、区间占位行 | 波动 <2%，无冲击后相位 |

## 三、统计规律摘要

| 维度 | 重大事件 | 叙事主题 |
|------|----------|----------|
| 冲击速度 | T+1~T+5 常 ≥3% | 缓慢抬升，T+20 才显现 |
| 回撤/反弹 | 冲击后 5–15 日常见 ≥30% 幅度回撤或反向反弹 | 回撤相对浅（CU 叙事峰值后约 -3.8%） |
| 持续期 | 20–40 日震荡为主 | 60 日+ 趋势（AU 2023 达 119 日） |
| 品种 | SC 地缘弹性最大；CU/AL 分化 | CU/AL/AU/AG 受益排序：CU ≈ AG > AU > AL |

## 四、代码映射（commodity-outlook-philosophy.js v1.30.2）

| 函数 | 作用 |
|------|------|
| `classifyNewsArchetype(title, notes, tags)` | → `shock_event` \| `narrative_theme` \| `routine` |
| `postShockPhase(klines, eventDate, asOfDate)` | → `spike` \| `pullback` \| `bounce` \| `consolidation` |
| `buildNewsArchetypeContext(newsImpact, id, klines, date, eventCtx)` | 汇总原型 + 冲击相位 + 研判提示 |
| `applyItemStimulusWeight` | shock 首次 ×1.28；narrative 衰减下限 0.82、×1.12 |

### 引擎/回测接线

- `evaluateInstrumentPhilosophy`：叙事品种 ×1.18；pullback/bounce 阶段 composite ×0.78
- `commodity-outlook-engine.js`：传入 `eventCtx`、`asOfDate`
- `commodity-outlook-backtest.js`：walk-forward 按 `barDate` 调用
- `news-tagged-loader.js`：命中行附带 `newsArchetype`
- UI `src/app.js`：研判逻辑区显示「资讯原型」行

### 与 v1.30 衰减/台阶模块协同

- **刺激衰减**（`eventStimulusDecay`）：shock 重复 headline 递减；narrative 衰减更慢
- **攻城台阶**（`trendStructureAnalyzer`）：pullback 相位与 `postShockPhase.pullback` 共振时降星
- **事件日历**（`ru_ukraine_supply` 等）：提供冲击起点日期供 `postShockPhase` 跨日检测
